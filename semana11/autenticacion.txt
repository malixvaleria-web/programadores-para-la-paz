SISTEMA DE AUTENTICACIÓN Y PROTECCIÓN DE RUTAS

El 'login' o inicio de sesión es el mecanismo de seguridad diseñado para verificar la identidad de un usuario mediante credenciales guardadas previamente, garantizando que quien ingresa sea realmente quien dice ser. En nuestra plataforma, ciertas rutas del servidor deben permanecer estrictamente protegidas porque ejecutan acciones administrativas delicadas, como modificar el estado de una causa comunitaria o eliminar registros del sistema. Si estas rutas se dejaran públicas, cualquier persona malintencionada podría alterar la base de datos o manipular el avance de los proyectos colectivos. Por motivos de seguridad y respeto a la privacidad ciudadana, el sistema jamás debe exponer públicamente contraseñas, números de cédula, direcciones físicas, números telefónicos, ni tokens o llaves privadas de APIs de automatización.
